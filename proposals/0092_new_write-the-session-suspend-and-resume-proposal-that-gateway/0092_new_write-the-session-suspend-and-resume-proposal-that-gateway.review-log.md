### Traps

**Do not restore the old SPEC-1b condition.** State plus unchanged generation is ABA-prone: the watchdog exit bumps nothing, so a re-entry restores the pair and a stale commit passes. The entry increment plus the incarnation condition replaces it.
**Do not restore `UpdatedAt` as guard or token.** The guard lost so every `resuming` exit uses one generation condition; the token lost because `AdvanceLastSeq` advances `UpdatedAt` before the commit.
**Do not restore the post-exit bump or the deleted SPEC-1b claims.** The next entry increments; two replicas claim before the entry write; the watchdog anchor moves with every row write.
**Terminal writers read `fromState` outside their mutator.** They bump the generation in a second Update (session_transitions.go); a §7.2 step 4 fidelity defect owned elsewhere; exclusivity holds because the commit requires `resuming`.
**Binding stamp.** `resume_rebind.go` stamped the pre-entry generation (`G−1`), which `reportSupersededByPeer` drops; CODE-4 item 5.4 restamps with `G`.
**No fence at bind, no fence-on-claim.** No stale coordinator addresses the replacement pod; §10.1.2 step 3 accepts RPCs on a pod with no fenced generation.
**Do not add a `resuming` guard to §10.1.2 step 1 or per acquirer.** SPEC-2a's step-0 tie plus SPEC-1b **Exits from `resuming`.** carry exclusivity; do not edit step 1's 0-row handling.
