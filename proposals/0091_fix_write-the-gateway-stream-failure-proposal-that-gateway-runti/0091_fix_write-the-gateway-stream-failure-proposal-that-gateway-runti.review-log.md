**Adapter behavior (code facts relied on throughout)**
- **Runtime exit ends Attach cleanly**: a runtime connection end (crash, kill, or clean exit) closes the fan-out, Attach returns nil, and the gateway sees io.EOF with no report; only the next Attach ends INTERNAL (Output returns errRuntimeConnectionEnded). The adapter sends nothing on a crash.
- **Adapter status mapping**: heartbeat miss → DeadlineExceeded; runtime output or envelope-write error → Internal; unopened session or no runtime → FailedPrecondition; gateway end → Canceled; hold-state rejection → Unavailable; generation-stale and fence refusals → FailedPrecondition/Aborted.
- **Heartbeat is per Attach stream**: no stream means no heartbeat; a hung shared runtime ends every slot stream, staggered over up to one heartbeat interval; heartbeat frames carry no sessionId and reach every stream.
- **Adapter demux**: session-scoped frames are demultiplexed per stream by sessionId; an unaddressed one on a multi-slot pod is rejected.
- **runtimeForSession** returns the Runtime whenever the slot exists, so a write to a dead runtime maps to INTERNAL.
- **Close and Shutdown return quickly on a hung runtime** (socket Close is a no-op; InProcessRuntime.Close ignores ctx).
- **No adapter `RUNTIME_CRASH` synthesis**: covered by F-4.7.27 (scheduled under 0087) and a summary **Defects** bullet; RECORDS-1 files nothing new for it.
- **SIGSTOP checkpoint**: pkg/adapter/embeddedcheckpoint sends SIGSTOP but nothing imports it; recorded as a summary **Defects** bullet.
- **Adapter grpc server** sets no MaxConcurrentStreams; keepalive PermitWithoutStream=true; held idle streams cause no GOAWAY.
