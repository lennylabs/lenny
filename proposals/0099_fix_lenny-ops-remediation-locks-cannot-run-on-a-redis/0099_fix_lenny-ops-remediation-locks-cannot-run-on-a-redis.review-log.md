### [non-spec.5.fix-G1.1]

DECISION: casScript reads `data` once and returns 1 when ARGV[2] is non-empty and equals the stored value, before the ARGV[1] compare — BECAUSE go-redis re-sends a script whose reply was lost (EOF, or read timeout with no per-command timeout; MaxRetries defaults to 3 and redisconn sets none), and without the check a replayed Steal re-decides on its own write and records the stealer as stolenFrom, and a replayed Extend bumps revision twice.
