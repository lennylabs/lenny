# Alertmanager routing recommendations

The chart does not bundle Alertmanager configuration. Routing is
deployer-specific (PagerDuty vs Slack vs OpsGenie vs email, on-call
rotations, per-team routing, severity-based escalation policies), so a
bundled default would either be wrong for most deployers or generic
enough to be useless. Use the recommendations below as a starting
point and adapt them to the deployment's escalation policies.

| Severity   | Recommended routing                                                                                  | Rationale                                                              |
| ---------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| critical | Page on-call (PagerDuty / OpsGenie) immediately; post to `#lenny-alerts-critical` Slack channel | Platform-affecting; needs human response within minutes                |
| warning  | Post to `#lenny-alerts` Slack channel; page only if unresolved >30 minutes                       | Indicates degradation but the platform is still serving traffic        |
| info     | Log or notification only                                                                              | Informational; no immediate action required                            |

## Example Alertmanager route block

The block matches the bundled rule severity labels. Replace receivers
with the deployer's escalation targets.

```yaml
route:
  receiver: lenny-default
  group_by: [alertname, severity]
  routes:
    - matchers:
        - severity = "critical"
      receiver: lenny-pagerduty
      continue: true
    - matchers:
        - severity = "warning"
      receiver: lenny-slack-warnings
    - matchers:
        - severity = "info"
      receiver: lenny-slack-info

receivers:
  - name: lenny-default
  - name: lenny-pagerduty
    pagerduty_configs:
      - service_key: ${PAGERDUTY_KEY}
  - name: lenny-slack-warnings
    slack_configs:
      - channel: "#lenny-alerts"
        api_url: ${SLACK_WEBHOOK_URL}
  - name: lenny-slack-info
    slack_configs:
      - channel: "#lenny-alerts-info"
        api_url: ${SLACK_WEBHOOK_URL}
```
