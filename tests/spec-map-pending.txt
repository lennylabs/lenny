# Two forms, matching the two checks:
#   - A bare repo-relative path (trailing `::TestName` removed) waives
#     the test-file existence check when the file is not on disk, and
#     waives the test-function check for every function in that file.

#     does not (a rename or removal left the map pointing at a gone
#     symbol). A new dangling reference in the same file is still caught.
# `#` starts a comment.

# corrected. A section listed in tests/spec-map-exceptions.yaml is
# exempt as a whole and does not need an entry here.
