# annotation to appear in the spec map under each section it lists. The
# orphan sweep in validate-maps covers two populations: the test files

# the packages a section claims under `packages`. The second population

# below accumulated: each one encodes behavior the map does not trace to
# it, and a reader of the section concludes the behavior is untested.

# One repo-relative path per line; `#` starts a comment. A path listed
# here is waived, so the gate ratchets on newly added drift while this
# backlog is worked down. Adding an entry is a last resort: the fix is to
# reference the file from the `tests` list of the section its `// spec:`
# annotation names, then delete its line here.
