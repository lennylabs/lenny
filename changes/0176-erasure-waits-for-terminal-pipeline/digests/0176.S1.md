## Defaults applied

- **The wait keeps the post-terminal window (O1, option (a)).** `admin.TerminalPipelinesPending` lists a session that is pipeline-pending or in its post-terminal window, and §12.8 states both arms.
- **`AfterTerminalWrite` writes the mark too.** EW-1 names `recordSessionCompleted`. The writers that call the exported post-terminal hook directly run no later step, so the hook is their whole pipeline, and the mark is written when it returns; without it their sessions would hold an erasure for a full budget. §7.1 states the rule for whichever replica runs the pipeline.
- **The mark write skips on an ended context.** `recordTerminalPipelineDone` checks `ctx.Err()` and writes nothing once the budget has elapsed, so the result does not depend on a store honoring the deadline.
