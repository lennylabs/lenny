A branch merges only when the latest finished selected run and the latest finished full run passed, or each failure has been fixed or reverted. A full run's failure counts as fixed when a full run started by hand on a commit with the fix passes, or when a targeted run of the failed tests on that commit passes and the next merge commit message names it.
