# Steps: 0129 GitHub credential add-on

## Steps

### 0129.S1 The github and github-enterprise kinds
- status: Planned
- aliases: [GH-1]
- lanes: [specification, code, documentation]
- depends-on: [0152.S1, 0152.S2, 0151.S7]

The design is in [GH-1](change.md#gh-1-the-github-and-github-enterprise-kinds), which covers the kinds and the repository check. The step also registers the request layout stated under [GH-3, "Request layout"](change.md#request-layout): the flavour, the API host, `apiBase`, `restPrefix`, `graphqlPaths`, the uploads path, and `attach` of each GitHub host type, because the kinds derive `apiHosts` and `attach` from it and `github-scoped` renders `{{apiBase}}` from it. The preset body stays in 0129.S3. The dependencies cover the VCS kind rules, the release check, and the kind registry with its extension points. The `sso_required` classification lands as GH-1 states it, and spike S4's result revises it if a SAML-enforced organization behaves otherwise.

### 0129.S2 Pull request authoring on GitHub
- status: Planned
- aliases: [GH-2]
- lanes: [specification, code, documentation]
- depends-on: [0129.S1, 0152.S3, 0151.S2, 0129.S3]

The design is in [GH-2](change.md#gh-2-pull-request-authoring-on-github). The dependencies cover the template, the attach rule, and the child tokens. It depends on 0129.S3 so that no session holds an API child with `pull_requests: write` on a VCS pool's API host before `github-deny` exists, and its tests of the preset's refusals need the preset. The step writes each child to the pending-revocation record that UC-2 of [`0151-user-credential-delivery`](../0151-user-credential-delivery/change.md#lifecycle-and-revocation-at-the-provider) defines before it releases the child, and implements one mint at a time per cache key, supersession revocation, and the `reauth-on-401` eviction of "Child tokens per session". It counts child mints and refreshes on the per-App counter that 0127.S1 adds under [`0127-egress-and-git`, "Credentials"](../0127-egress-and-git/change.md#credentials), which the step reaches through its dependencies. Open decisions 2, 3, and 7 touch this step. The spikes S1, S2, S2b, S3, S3c, and S15 under ["Validation owed"](#validation-owed) must pass before the step starts.

### 0129.S3 The github-deny preset
- status: Planned
- aliases: [GH-3]
- lanes: [specification, code, documentation]
- depends-on: [0151.S4, 0152.S3, 0129.S1]

The design is in [GH-3](change.md#gh-3-the-github-deny-preset). The dependencies cover the rule evaluator, the preset format, the default preset on a VCS pool's API host, and the request layout that 0129.S1 registers. The step also adds the scheduled CI job of ["Keeping `github-deny` current"](change.md#keeping-github-deny-current). Open decisions 4 and 6 touch this step.

## Validation owed
