- **The quota adapter.** `admin.QuotaCheckpointReconciler` takes the checkpoint service through a small interface, `CheckpointReconciler`, so its test needs no checkpoint store. The test moved with it as `TestQuotaCheckpointReconcilerMapsScopeResultAndErrors`.

The composition root hands each `With*` an admin adapter whose field is a seam interface: `SeamRevokeHook`, `SeamUserPods`, `SeamRevocationCache`, `SeamPoolCredentialRevoker`, `SeamUserLeaseRevoker`, `SeamKMSProbe`, `SeamClientSecrets`, `SeamLeaseDenials`, `SeamElicitationFloor`, or `SessionTerminator`.

The binding-release fan-out stays in `cmd/lenny-gateway` and reaches `AdminSeam` through `sessionserver.UserBindingReleases`. `GWSEAM-LastTenantKMSProbe` sits beside `GWSEAM-ProbeTenantKMS`, because the router also reads the time of the last successful probe.
- **The step's scope.** The first part did not build the route registration work of decisions 3, 24, and 34, the routes still mounted in `cmd/lenny-gateway`, the decision 7 move of the admin router's constructor and flags, or the split of `sessionserver`'s pipeline files. - **The internal listener's routes.** The `/internal/` paths, `/healthz`, `/readyz`, and `/metrics` register on the internal listener; the platform health API, under `/v1/admin/health`, stays on the client listener as part of the admin API. Both listeners share one mux, so the classification changes no answer.
- **Prefix routes.** Each route that `main` mounted as a path prefix for every method, such as `/v1/admin/`, `/playground/`, and the session paths, registers for `seam.MethodAny` under the same pattern, so the mux answers as it did, and a handler that dispatches by method keeps its own 405 answers. - **The session handler's patterns.** The session handler is built once per listener and mounted under every session path of that listener, where `main` built one per mounted prefix; each build was the same mux.
- **The forwarded Open Responses turn.** `POST /v1/responses` registers on the forward listener only when the forward listener is built, as `main` mounted it only then.
- **`connector-oauth-client-secret-key`.** The flag stays in `cmd/lenny-gateway`, because it configures the connector secret resolver that the session core holds and serves through `GWSEAM-ResolveConnectorSecret`, and its default is a constant of the confined `connectorsecret` package (open decision 67).
- **Flag packages.** Each moved flag joins the package of the part that reads it, as `uploadhandler.Flags` and `playground.Flags` did, rather than one flag package for the API front. `idempotency-max-body-bytes` joins `pkg/idempotency/idempotencymw`, the request pipeline's idempotency stage.
- **Harnesses.** `tests/testinfra/apifront` gives a test's session server the API front's route table, and `uploadwire`, `toolwire`, and `streamwire` register their parts through it, so each harness mounts the routes `main` mounted.
