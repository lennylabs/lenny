- **Package names (decision 6).** Every moved package keeps its name: `subsystem` and `extractionthreshold` under `seam` (the seam model; renaming the seams and their Helm values is out of scope), `semver` under `pkg/common`, `prestop` and `drainreadiness` under `drain`, `gcpause` and `capacityplanning` under `scaling`, `health` and `health/backends` under `opsendpoints`, `gatewaymetrics`, `gatewayleader`, `pdbwatcher`, `devmode`, and `tlsprobe` under `replica`, and `playground` as `pkg/gateway/playground`. Each name says what its package holds within its part.
- **Package documentation.** Each moved gateway package has a `doc.go` that carries its package comment and ends with its page codes: `GW` for the seam model and the replica, `GWDRAIN`, `GWSCALE`, `GWOPS`, and `PLAY`. The comments that quoted the specification were reworded, and `// spec:` lines inside package comments became prose. `pkg/common/semver` names no page code, because no specification page owns it.
- **Admission without a function (`Subsystem.Admit`).** The VCS token read holds the Token Service client, which GW-R2 confines, so the seam model may not receive a function that calls it. `Admit` splits `Do` into admission and a `done` call that releases the limiter slot and records the outcome; `Do` is built on it, and the read calls the RPC itself between the two.
- **The JWT sign counter's component.** `RecordJWTSignRequest` takes the component label from its caller, the composition root's breaker observer, which passes `jwt.SignComponentGateway`, so the gateway metrics import no signing package.
- **The request-metrics stage (`pkg/gateway/api/requestmetrics`).** The middleware that wraps the authentication middleware belongs to the API front's request pipeline, which may hold it. `requestmetrics.Wrap` reports through a `Recorder` that the gateway metrics implement with `ObserveRequest` and `AddInflightRequests`, and `InflightRequests` still reads the count. The status recorder with its `Flush` and `Hijack` forwarding moved with it, and so did its tests.
- **The audit appender (open decision 25, built as recommended).** `audit.Appender` and `audit.ChainSetAppender` in `pkg/audit` replace `policy.AuditAppender` and `policy.ChainSetAppender` everywhere, with no alias left behind.
