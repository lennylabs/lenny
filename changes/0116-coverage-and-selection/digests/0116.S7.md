## What the step built

- `scripts/specshift/annotation/lint.go`: the rule `IdentifierInTestName`. A test function name, or a subtest name written as a string literal in a `t.Run` call, on a changed line, is refused when it spells a requirement or issue identifier. A code of two to nine upper-case letters followed by a hyphen or an underscore and `R` or `I` and a number is refused by its form. A dropped hyphen, or a code with only its first letter in upper case, is refused for a page code or alias that `spec/registry.json` carries. A space in a subtest name counts as an underscore, as `go test` writes it. The finding names the identifier in its canonical form, such as `CLAIM-R4`.
